# 2048（金币版 v1.1）

方向键 / 滑动合成大数：合成 128、256 以上按金币规则给金币；合成失败（死局）后可花金币复活继续。

- 本体文件就在本目录：`index.html`（可读源码）+ `sw.js` + `manifest.json` + `icon-*.png`。
- 页面里没有外部素材（样式、图形都内嵌代码），`assets-src/` 目前为空——以后放图、音效原图到这里，**不会传上云**。
- 改完代码要手动把 `sw.js` 里的缓存名 `game2048-vN` 数字加一，再 `bash deploy.sh`（本游戏没有 GAME_VER 常量，bump-version.sh 不适用）。
- 孩子的进度存在设备 localStorage：最高分 `best2048`、金币 `coins2048`、每日时长、音效开关。
- 一次性归零键：`__wipe2048 = 'w2'`。想再清一次成绩，把它改成 `w3` 再部署。
